# AtCoder の解法例

各 `.cpp` は定式化・前処理・解の復元を含むモデルです。リポジトリのルートで `python3 tools/make_submissions.py` を実行すると、ソルバを埋め込んだ提出用ソースを `build/submissions/atcoder/` に生成します。生成したファイル全体を C++17 以上で提出できます。

## ABC002 D — 派閥

[問題](https://atcoder.jp/contests/abc002/tasks/abc002_4) / [コード](abc002_d.cpp)

議員 $i$ を選ぶ二値変数 $x_i$ を置き、知り合いでないペアに $x_i+x_j\le1$ を課し、$\sum_i x_i$ を最大化します。選んだ任意の2人が知り合いになるため、最大クリークの人数を求められます。

## ABC338 C — Leftover Recipes

[問題](https://atcoder.jp/contests/abc338/tasks/abc338_c) / [コード](abc338_c.cpp)

料理 A、B の人数を非負整数変数 $x,y$ とします。材料の在庫を $Q_i$、1人分の消費量を $A_i,B_i$ とすると、制約は $A_i x+B_i y\le Q_i$、目的は $x+y$ の最大化です。各料理を単独で作れる最大人数から、変数の上限も求めます。消費量が0の材料は、その料理の上限計算には使いません。

## ABC326 G — Unlock Achievement

[問題](https://atcoder.jp/contests/abc326/tasks/abc326_g) / [コード](abc326_g.cpp)

実績を獲得する二値変数 $z_i$ と、技能が各要求レベルに達している二値変数 $x_{j,k}$ を置きます。要求されないレベルは省き、残したレベルを $1=t_{j,0}<t_{j,1}<\cdots$ とします。

隣り合う要求レベル間の含意 $x_{j,k}\le x_{j,k-1}$（$k\ge2$）と、実績から要求レベルへの含意 $z_i\le x_{j,k}$ を課します。レベル1の要求には制約が不要です。目的関数は

$$
\sum_i A_i z_i-\sum_{j,k} C_j(t_{j,k}-t_{j,k-1})x_{j,k}
$$

です。増分費用を足すことで、実際の技能レベルの費用と一致します。含意だけで表される最大重み閉包のモデルであり、LP 緩和の頂点も整数です。

## ABC354 G — Select Strings

[問題](https://atcoder.jp/contests/abc354/tasks/abc354_g) / [コード](abc354_g.cpp)

包含関係にある文字列を同時に選ばず、重みの和を最大化します。同じ文字列は最も重い1個だけ残します。「$i$ が $j$ の部分文字列」を $i<j$ とすると、選びたい集合はこの半順序の反鎖です。

各文字列に二値変数 $p_i,q_i$ を置き、$q_i\le p_i$ と、包含関係に対する $p_i\le q_j$ を課します。$p_i-q_i=1$ の文字列を選び、$\sum_i w_i(p_i-q_i)$ を最大化します。$i<j$ の両方を選ぶと $p_i=1,q_j=0$ になり、制約に反します。逆に任意の反鎖に対して、その上側の集合で $p$、厳密に上側の集合で $q$ を1にすれば表現できます。

途中の文字列を介して導ける包含関係の制約は省きます。差分制約と整数の上下限が整数 LP を作るため、単純なペア競合より強い定式化になり、`cuts=0` で解きます。

## ABC165 C — Many Requirements

[問題](https://atcoder.jp/contests/abc165/tasks/abc165_c) / [コード](abc165_c.cpp)

隣接差 $g_j=A_{j+1}-A_j$ と、条件の報酬を得る二値変数 $y_i$ を使います。$g_j\ge0$、$\sum_j g_j\le M-1$ とすれば、$A_1=1$ から有効な非減少数列を作れます。

条件 $(a_i,b_i,c_i,d_i)$ に対し $S_i=\sum_{j=a_i}^{b_i-1}g_j$、$C=M-1$ と置き、

$$
c_i y_i\le S_i\le C-(C-c_i)y_i
$$

を課して $\sum_i d_i y_i$ を最大化します。$y_i=1$ なら $S_i=c_i$、0なら元の範囲だけが残ります。同じ区間で異なる差を要求する報酬は同時に得られないので、その $y_i$ の和を1以下にします。

差は連続変数にできます。報酬変数を固定すると、残る制約は整数の右辺を持つ区間和の制約であり、実行可能なら整数の差の解も存在するためです。各座標を改善する局所探索で初期解を作り、報酬変数の整数計画で最適性を確認します。

## ABC180 E — Aerial Cities

[問題](https://atcoder.jp/contests/abc180/tasks/abc180_e) / [コード](abc180_e.cpp)

移動費用は $|x_i-x_j|+|y_i-y_j|+\max(0,z_j-z_i)$ です。閉じた巡回では高さの増減の和が0なので、上昇量の合計は高さの絶対差の合計の半分です。無向辺の費用を

$$
D_{ij}=2|x_i-x_j|+2|y_i-y_j|+|z_i-z_j|
$$

とすると、巡回路の元の費用は $\sum D_{ij}/2$ になります。

各無向辺に二値変数を置き、各都市の次数を2にして費用を最小化します。整数解が複数の閉路に分かれたら、各閉路の頂点集合 $S$ の境界を横切る辺の和を2以上にする制約を追加します。1本の巡回路になるまで解き直します。その時点で緩和モデルの最適解が巡回路でもあるため、元問題でも最適です。

最近傍法と 2-opt で初期解を作り、専用の部分巡回除去制約を使うため `cuts=0` にします。都市が2個の場合は、同じ無向辺を往復する費用を直接計算します。

## ABC187 F — Close Group

[問題](https://atcoder.jp/contests/abc187/tasks/abc187_f) / [コード](abc187_f.cpp)

全頂点をできるだけ少ないクリークへ分割します。Bron–Kerbosch 法で極大クリークを列挙し、クリーク $K$ の使用数を非負整数変数 $x_K$ とします。各頂点へ $\sum_{K\ni v}x_K\ge1$ を課し、$\sum_K x_K$ を最小化します。

重複を許す被覆として解いてよい理由は、各頂点をどれか1つのクリークへ割り当てても各組がクリークのままだからです。逆に分割の各クリークを極大クリークへ拡張すれば被覆になるので、極大クリークだけでも最適値は変わりません。

未被覆の頂点を最も多く覆うクリークを順に選び、初期解と使用数の上限 $U$ を作ります。$\sum_K x_K\le U$ の1本の制約で全変数も有界になるため、個別の上限制約は不要です。

## ABC338 F — Negative Traveling Salesman

[問題](https://atcoder.jp/contests/abc338/tasks/abc338_f) / [コード](abc338_f.cpp)

負辺を含む有向グラフで、全頂点を訪れる最小費用の歩道を求めます。負閉路がないことを利用し、Floyd–Warshall 法で全点対最短距離 $d_{ij}$ を求めます。互いにどちらからも到達できない頂点のペアがあれば、全頂点を訪れる歩道は存在しません。

最短距離グラフでは全頂点を1回ずつ並べる Hamiltonian path を求めれば十分です。歩道の内部の重複頂点は、三角不等式で費用を増やさずに省けます。始終が同じ閉路だけが残った場合も、負閉路がないので非負費用の辺を1本切れます。逆に最短距離の辺を元の経路へ展開すれば、全頂点を訪れる歩道になります。

全頂点と費用0の辺で結ぶダミー頂点を加え、始終が自由な道を有向巡回路に変えます。到達可能な有向辺に二値変数を置き、各頂点の出次数と入次数を1にします。ダミーの入次数の等式は他の等式から従うため省きます。

複数の閉路ができたら、各頂点集合 $S$ から外へ出る辺の和を1以上にする制約を追加し、単一閉路になるまで求解します。ダミーを外して訪問順を得て、最短経路の情報で元の歩道も復元できます。

到達可能性を保つ貪欲法と有向費用を再計算する区間反転で初期解を作ります。各頂点の出辺の最小費用をその行から引き、出次数1により一定となる補正額を最後に戻します。専用の部分巡回除去制約を使い、`cuts=0` で解きます。
