# QOJ の解法例

各 `.cpp` はモデルのソースです。リポジトリのルートで `python3 tools/make_submissions.py` を実行すると、ソルバを埋め込んだ提出用ソースを `build/submissions/qoj/` に生成します。生成したファイル全体を C++17 以上で提出できます。

## 10266 — Bin Packing

[問題](https://qoj.ac/problem/10266) / [コード](qoj10266.cpp)

容量12の箱にサイズ1〜12の物を詰める最小箱数を求めます。箱の充填パターンを列挙し、パターン $p$ の使用数を非負整数変数 $x_p$ とします。サイズ $k$ の需要を $n_k$、パターン内の個数を $a_{p,k}$ とすると、制約は $\sum_p a_{p,k}x_p\ge n_k$、目的は $\sum_p x_p$ の最小化です。

容量がちょうど12になる77パターンだけで十分です。空きは仮想のサイズ1の物で埋められ、逆に需要を超える物は取り除けるので、この被覆と元の梱包は同じ最適箱数を持ちます。

First Fit Decreasing で実行可能な梱包を作り、箱数の上限 $U$ と初期解にします。空きをサイズ1で埋めて列挙パターンの解へ変換します。体積による下限 $\lceil\sum_k k n_k/12\rceil$ と、$\sum_p x_p\le U$ も追加します。物を1個ずつ変数にせず、容量の小ささを利用してパターン数へ圧縮する例です。

## 3699 — Vertex Cover

[問題](https://qoj.ac/problem/3699) / [コード](qoj3699.cpp)

最小頂点被覆を、補集合である最大独立集合へ変換します。この問題では全ての辺が先頭30頂点のどれかに接続し、これらが被覆の上界を与えます。

葉があればその隣を被覆へ入れます。また、現在得られる被覆の上界より次数が大きい頂点も入れます。その頂点を入れないと全隣接頂点が必要になり、上界を超えるためです。確定した頂点と辺を除いた後、連結成分に分けます。

同じ開近傍を持つ頂点は互いに隣接せず、独立集合に入れるなら全て入れる最適解が存在します。そこで1群に統合し、群の人数を重みにします。群を選ぶ二値変数 $x_i$ に、群間の辺ごとに $x_i+x_j\le1$ を課し、$\sum_i w_i x_i$ を最大化します。

さらにクリーク $K$ に $\sum_{i\in K}x_i\le1$ を加えて LP 緩和を強め、重みと次数から貪欲な初期解を作ります。成分の頂点数から最大独立集合の人数を引き、前処理で確定した被覆数を足すと答えです。

## 5785 — Mine Layer

[問題](https://qoj.ac/problem/5785) / [コード](qoj5785.cpp)

各セルの手掛かりは、そのセルを中心とする3×3領域の地雷数です。地雷配置を $X$、手掛かりを $B$、主対角と隣の対角が1の三重対角行列を $A_n$ とすると、全条件は $A_R X A_C=B$ です。目的は中央行の地雷数の最大化です。

1次元の等式は、先頭の値を置いて $x_{i+1}=b_i-x_i-x_{i-1}$ という漸化式で解けます。$A_n$ は $n\bmod3=2$ のときだけ特異で、その核は $h=(1,-1,0,1,-1,0,\ldots)$ です。行・列方向に等式を解いて特解 $Q$ を求め、自由度だけを IP の変数に残します。

両方向が特異な場合は $X_{ij}=Q_{ij}+\alpha_i h_j+h_i\beta_j$ と表せます。一方向だけが特異ならその項だけを残し、どちらも非特異なら配置は一意です。両方向の場合は重複する自由度を1個取り除き、変数数を

$$
R[C\bmod3=2]+C[R\bmod3=2]-[C\bmod3=2][R\bmod3=2]
$$

にします。$[P]$ は条件 $P$ が真なら1、偽なら0です。

各セルに $0\le X_{ij}\le1$ を課し、中央行の和を最大化します。各制約は行側・列側の自由変数を高々1個ずつ含み、符号を揃えると二部グラフの接続行列になるので、残る LP も整数解を持ちます。`cuts=0` で解き、目的値に特解の中央行の和を足して答えを得ます。

## 20736 — 隣接する要素の最小公倍数の和の最大化

[問題](https://qoj.ac/problem/20736) / [コード](qoj20736.cpp)

値 $i$ の出現回数を $c_i$ とし、値 $i,j$ が隣接する回数を非負整数変数 $x_{ij}$ ($i\le j$) にします。目的は $\sum_{i\le j}\operatorname{lcm}(i,j)x_{ij}$ の最大化です。出現する値だけを頂点にし、同じ値同士の隣接は自己ループにすることで、高々28変数に圧縮します。

辺数は $\sum x_{ij}=n-1$、頂点 $i$ の次数は $d_i=2x_{ii}+\sum_{j\ne i}x_{\min(i,j),\max(i,j)}$ です。$2c_i-2\le d_i\le2c_i$ とすると、次数の不足 $2c_i-d_i$ の合計は2になります。これは両端が同じ値ならその値で2、異なる値ならそれぞれで1となる条件です。

まず次数と辺数の制約だけで解き、結果が非連結なら各連結成分 $S$ に対し、集合の内外を結ぶ辺の本数を1以上にする制約を追加して再求解します。補集合との重複も除くので、追加する制約は高々63本です。連結な最適解が得られた時点で終了します。連結で奇数次数の頂点が0個または2個の多重グラフはオイラー路を持ち、その頂点列は各値をちょうど $c_i$ 回ずつ使います。従って、このモデルと元の並べ替え問題は同じ最適値を持ちます。

入力の並びを初期解として渡し、整数解の隣接数から答えを整数演算で計算します。値が1種類だけなら $(n-1)i$ を直接返します。
